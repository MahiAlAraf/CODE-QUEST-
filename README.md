# Code Quest: Escape from the Compiler Kingdom

A text-based RPG written in C that teaches core programming concepts through story-driven quiz battles.

A virus called the **NULL POINTER** has shattered the Compiler Kingdom. As the last Code Apprentice, you must restore four broken lands — each guarded by challenges on a different C topic — before facing the NULL POINTER itself in the final battle.

## Regions

- **Variable Village** — data types & variable declarations
- **Loop Forest** — `for` / `while` loops, off-by-one bugs
- **Array Cave** — array indexing & bounds
- **Function Falls** — pass-by-value, recursion, scope
- **Pointer Peak** — pointers & pointer arithmetic
- **Silent Corridor** — two guards testing strings (`strcpy`, `strcat`, `strlen`, `strcmp`)
- **The NULL POINTER** — a final, no-multiple-choice boss challenge combining everything

## Features

- HP-based battle system — wrong answers cost HP, correct answers earn Coins & XP
- A small in-game shop (Elixir, Iron Shield) to prep for tougher fights
- Optional side quests for bonus rewards
- Answer explanations for every question, right or wrong

## Why

Built as a way to practice and review C fundamentals — variables, loops, arrays, pointers, and strings — through an interactive story instead of plain drills.
